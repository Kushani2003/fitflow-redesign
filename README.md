# fitflow-redesign

FitFlow is a redesigned fitness tracking application focused on personalized AI workout plans, social accountability, nutrition tracking and progress visualization.

## Technology Stack
- React Native
- Node.js + Express
- Firebase
- TensorFlow Lite
- ML Kit
- Cloud AI services

## Main Features
- AI Daily Flow personalized workouts
- Flexible workout builder
- Social challenges and private circles
- Camera-based nutrition logging
- Progress dashboard
